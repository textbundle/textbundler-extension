TextBundler

TextBundler captures the article on the current web page and saves it as a self-contained TextBundle .textpack archive — Markdown body plus all referenced images, packaged into a single file you can drop into any TextBundle- aware editor.

How it works

  1. Click the toolbar icon, or right-click and choose Archive Page as TextBundle.
  2. Mozilla Readability extracts the main article from the current page.
  3. The HTML is converted to Markdown, images are downloaded, and everything is zipped into a .textpack file.
  4. Your browser downloads the file to your default downloads folder.

Install

Pre-built .zip packages for Chrome and Firefox are attached to every GitHub release. Store listings are in preparation.
